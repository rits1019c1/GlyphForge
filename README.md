# GlyphForge

**プロフェッショナルかつ直感的なWebフォント制作エディタ。**
iPad（Apple Pencil）とPC（マウス/ペンタブ）の双方に対応し、ベクター描画から `.otf` ファイル書き出しまでをブラウザ完結で行います。インストール不要、単一 HTML ファイルで動作します。

## 機能一覧

### 描画ツール

| ツール | ショートカット | 説明 |
|--------|-------------|------|
| 直線 | `L` | 2点間を正確な直線で結ぶ |
| 曲線 | `C` | 3クリックでクアドラティックベジェ曲線（始点 → 制御点 → 終点） |
| フリーハンド | `F` | ペンで自由に描画。筆圧感知ON時は線幅が動的に変化 |
| 図形 | `R` | ドラッグで矩形を挿入 |
| 選択・移動 | `V` | ストロークを選択してドラッグ移動 |
| 消しゴム | `E` | クリックしたストロークを削除 |

### キーボードショートカット

| 操作 | キー |
|------|------|
| 元に戻す | `Ctrl + Z` |
| やり直し | `Ctrl + Y` / `Ctrl + Shift + Z` |
| 選択中のストロークを削除 | `Delete` / `Backspace` |
| 操作キャンセル（曲線の途中など） | `Esc` |
| ズームイン/アウト | スクロール / `+` `−` ボタン |

### 筆圧感知

トップバーの **筆圧感知** トグルをONにすると、Apple PencilやWacom等の Pointer Pressure API 対応デバイスで線幅が動的に変化します。

### タイポグラフィガイド

キャンバス上に常時表示されるガイドラインで、文字の収まり具合を確認できます。

| ライン / ゾーン | 色 | 説明 |
|--------------|---|------|
| ascender ライン | 青 | 上付き記号などが届く上限 |
| cap height ライン | 紫 | 大文字の上端（em box の上辺） |
| em box | 紫の枠 | 文字が基本的に収まる領域 |
| x-height ライン | 緑の点線 | 小文字の上端（`a` `e` など） |
| baseline ライン | 紫の実線（太） | 文字が乗る基準線 |
| descender zone | オレンジのゾーン | `g` `j` `p` などのしっぽが出る領域 |

右端には UPM換算の数値（`+700` / `+500` / `0` / `−200`）も表示されます。

### 画像下絵

1. トップバーの **下絵** ボタンから画像を選択
2. 自動的にグレースケール＋コントラスト強調処理が適用される
3. 右パネルの **透過度** で重ね具合を調整（5〜90%）
4. **下絵を削除** ボタンで除去

### グリフの追加・削除

- 左サイドバー下部の入力欄に文字を1文字入力して **＋ 追加** でキャンバスを即座に生成
- グリフ一覧のアイテムにホバーすると現れる **×** ボタンで削除（確認ダイアログあり）

### 部首（コンポーネント）システム

**登録**
描画完了後、左サイドバーの **現在の描画を部首として登録** で登録。ストロークデータごと保存されます。

**挿入**
部首チップをクリック、またはトップバーの **部首挿入** ボタンからモーダルで選択して現在のキャンバスに追加。

**編集（各チップの ⚙ ボタン）**

| 操作 | 内容 |
|------|------|
| 現在のキャンバスで上書き登録 | 選択中グリフの描画内容で部首ストロークを差し替え |
| 全グリフへ変更を同期 | 部首を更新後、配置済みの全グリフへ自動反映 |
| 削除 | ライブラリから除去 |

## ファイル管理

### 自動保存（localStorage）

描画・グリフ追加/削除・アンドゥ/リドゥ・読み込みのたびに、500ms のデバウンスを挟んでブラウザのローカルストレージへ自動保存されます。ブラウザを閉じて再度開いても前回の状態が復元されます。

**ストレージキー構成:**

| キー | 内容 |
|------|------|
| `GF_meta` | グリフリスト・部首・メトリクス・フォント名 |
| `GF_gd_0`, `GF_gd_1`, … | グリフのストロークデータ（80KB ごとに分割） |
| `GF_nchunks` | チャンク数 |

ステータスバーの **💾 自動保存: HH:MM:SS** で最終保存時刻を確認できます。クリックするとストレージリセットのダイアログが開きます。

> **容量上限について:** ブラウザの localStorage は通常 5〜10MB が上限です。グリフ数が非常に多い場合は上限に達することがあります。その際はステータスバーのドットが赤くなり、手動保存（.txt）を促すトーストが表示されます。

### 手動保存（.txt）

トップバーの **保存** ボタンから任意のタイミングでダウンロードできます。

```
形式: (フォント名)_YYYYMMDD_HHMMSS.txt
内容: JSON（グリフリスト・部首データ・全ストローク・メトリクス）
```

```json
{
  "fontName": "MyFont",
  "glyphs": [...],
  "radicals": [...],
  "glyphData": { "A": { "strokes": [...] }, ... },
  "metrics": { "advanceWidth": 600, "ascender": 800, "descender": -200, ... },
  "savedAt": "2026-05-12T10:30:00.000Z"
}
```

### 読み込み（**読み込み** ボタン）

| 形式 | 挙動 |
|------|------|
| `.txt`（GlyphForge 保存データ） | グリフ・部首・ストローク・メトリクスを完全復元 |
| `.otf` / `.ttf` | opentype.js で解析し、パスコマンドをストロークに変換してインポート。ascender/descender も自動取得 |

### OTF 書き出し

トップバーの **OTF書き出し** ボタンから `.otf` ファイルを生成します。

**処理フロー:**
1. 各グリフのストロークを opentype.js の `Path` に変換
2. Canvas 座標（左上原点）→ フォント座標（左下原点）に Y 軸反転＋スケーリング（`unitsPerEm = 1000`）
3. `font.download()` でブラウザからそのままダウンロード

**設定可能なメトリクス（右パネル）:**

| 項目 | 説明 | デフォルト |
|------|------|-----------|
| 幅 (advanceWidth) | グリフの送り幅 | 600 |
| 左 sb | 左サイドベアリング | 50 |
| 右 sb | 右サイドベアリング | 50 |
| ascender | ベースラインからの上端 | 800 |
| descender | ベースラインからの下端 | -200 |

## 技術スタック

| 項目 | 技術 |
|------|------|
| 言語 | HTML5 / CSS3 / Vanilla JavaScript |
| 描画 | Canvas 2D API |

## 既知の制限

- フリーハンドストロークは OTF 変換時に折れ線（LineTo の連続）としてエンコードされます。スムージングは今後の改善項目です。
- OTF 書き出しはストロークのパスをそのまま記録するため、「アウトライン（塗りつぶし）」にはなりません。Glyphs や FontForge 等でのアウトライン化を推奨します。
- OTF/TTF 読み込み時の Cubic Bézier（`C` コマンド）は中点で Quadratic に近似されます。
