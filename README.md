# GlyphForge

**プロフェッショナルかつ直感的なWebフォント制作エディタ。**  
iPad（Apple Pencil）とPC（マウス/ペンタブ）の双方に対応し、ベクター描画から `.otf` ファイル書き出しまでをブラウザ完結で行います。

---

## 機能一覧

### 描画ツール

| ツール | ショートカット | 説明 |
|--------|-------------|------|
| 直線 | `L` | 2点間を正確な直線で結ぶ |
| 曲線 | `C` | 3クリックでクアドラティックベジェ曲線を描く（1点目: 始点 / 2点目: 制御点 / 3点目: 終点） |
| フリーハンド | `F` | ペンで自由に描画。Apple Pencilの筆圧に連動 |
| 図形 | `R` | ドラッグで矩形を挿入 |
| 選択・移動 | `V` | ストロークを選択してドラッグ移動 |
| 消しゴム | `E` | クリックしたストロークをポイント単位で削除 |

### 操作

| 操作 | ショートカット |
|------|-------------|
| 元に戻す | `Ctrl + Z` |
| やり直し | `Ctrl + Y` / `Ctrl + Shift + Z` |
| 選択中のストロークを削除 | `Delete` / `Backspace` |
| 操作キャンセル | `Esc` |
| ズームイン/アウト | スクロール or トップバーの `+` / `−` |

### 筆圧感知

トップバーの **筆圧感知** トグルをONにすると、Apple PencilやWacom等のPointer Pressure API対応デバイスで線幅が動的に変化します。

### 画像下絵

1. トップバーの **下絵** ボタンから画像を選択
2. 自動的にグレースケール＋コントラスト強調処理が適用される
3. 右パネルの **透過度** スライダーで重ね具合を調整
4. **下絵を削除** ボタンで除去

### 部首（コンポーネント）システム

- 描画完了後、左サイドバーの **現在の描画を部首として登録** ボタンで登録
- 登録済みの部首チップをクリック、またはトップバーの **部首挿入** ボタンでモーダルから選択して挿入
- 挿入時はストロークデータがコピーされるため、配置先を個別に編集可能

### グリフの追加

左サイドバー下部の入力欄に文字（例: `漢`、`@`）を1文字入力して **＋ 追加** を押すと、その文字の編集キャンバスが即座に生成されます。

## ファイル管理

### 作業データ保存（.txt）

トップバーの **保存** ボタンから保存できます。

```
形式: (フォント名)_YYYYMMDD_HHMMSS.txt
内容: JSON（グリフリスト・部首データ・全ベクターストローク・メタ情報）
```

保存例:
```json
{
  "fontName": "MyFont",
  "glyphs": [...],
  "radicals": [...],
  "glyphData": { "A": { "strokes": [...] }, ... },
  "savedAt": "2026-05-12T10:30:00.000Z"
}
```

### OTF書き出し

トップバーの **OTF書き出し** ボタンから `.otf` ファイルを生成できます。

**処理内容:**
1. 各グリフのストロークを opentype.js の `Path` オブジェクトに変換
2. Canvas座標（左上原点）→ フォント座標（左下原点）にY軸反転・スケーリング（`unitsPerEm = 1000`）
3. `font.download()` でブラウザからそのままダウンロード

**右パネルから設定可能なメトリクス:**

| 設定項目 | 説明 | デフォルト |
|----------|------|-----------|
| 幅 (advanceWidth) | グリフの送り幅 | 600 |
| 左 sb | 左サイドベアリング | 50 |
| 右 sb | 右サイドベアリング | 50 |
| ascender | ベースラインからの上端 | 800 |
| descender | ベースラインからの下端 | -200 |

## 技術スタック

| 項目 | 技術 |
|------|------|
| 言語 | HTML5 / CSS3 / Vanilla JavaScript |
| 描画 | Canvas 2D API |
| フォント生成 | [opentype.js](https://opentype.js.org/) v1.3.4 |
| 画像処理 | CSS `filter: grayscale(1) contrast(1.5)` |
| フォント | Noto Sans JP (Google Fonts) |
| ポインタ入力 | Pointer Events API (`pointerdown/move/up` + `setPointerCapture`) |
| 依存関係 | なし（CDN経由のみ、インストール不要） |

---

## 使い方

単一の `.html` ファイルなので、インストール不要です。

```bash
# ダウンロードしてブラウザで開くだけ
open GlyphForge.html
```

または任意のWebサーバーで配信:

```bash
# Python
python3 -m http.server 8080

# Node.js (npx)
npx serve .
```
